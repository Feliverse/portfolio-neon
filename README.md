# Portfolio

**Proyecto**: Sitio web de portafolio personal (plantilla estática)

**Autor**: Felipe Haybar Valenzuela

**Descripción**:
- **Resumen**: Proyecto inicial de un portfolio personal con estructura mínima: página HTML, estilos CSS, script JS e imágenes.
- **Objetivo**: Mostrar proyectos y datos personales en una página estática y fácil de desplegar.

**Contenido del repositorio**:
- **index**: `index.html` — Página principal del portafolio.
- **estilos**: `style.css` — Hoja de estilos principal.
- **scripts**: `script.js` — Lógica JavaScript del sitio.
- **imágenes**: `img/` — Carpeta para assets gráficos (fotos, íconos, etc.).
- **licencia**: `LICENSE` — Licencia MIT aplicada al proyecto.

**Tecnologías**:
- HTML5
- CSS3
- JavaScript (vanilla)

**Cómo ejecutar / probar localmente**:
- Opción rápida: abrir `index.html` en cualquier navegador.
- Servidor local (recomendado para algunas APIs o rutas relativas):

```bash
# Python 3 (desde la raíz del proyecto)
python -m http.server 8000
# Luego abrir http://localhost:8000
```
